# Code-Tagger: code markup tool (frontend)

Source code online tagging tool (frontend)

Backend project: [Code-Tagger-Backend](https://gitee.com/rvsmart-porting/code-annotation-backend)

## Project Objective

This project belongs to [RVSmartPorting Community](https://gitee.com/rvsmart-porting).
This is an aid for the study of RISC-V software migration techniques.
The goal is to provide a convenient online code annotation tool for
analyzing open source software code.

## How to use

* **install dependencies**: `npm install`
* **compile and run**: `npm run serve`
* **minimal build**: `npm run build`
* **style check**: `npm run lint`
