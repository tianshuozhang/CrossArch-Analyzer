# Code-Tagger：代码标注工具（前端）

源代码在线标注工具（前端）

后端项目：[Code-Tagger-Backend](https://gitee.com/rvsmart-porting/code-annotation-backend)

## 项目目标

本项目是 [RVSmartPorting 社区](https://gitee.com/rvsmart-porting)
针对 RISC-V 软件迁移技术研究的辅助工具，
目标是为分析开源软件代码提供一个便捷的在线代码标注工具。

## 使用方法

* **安装依赖**：`npm install`
* **编译运行**：`npm run serve`
* **最小构建**：`npm run build`
* **风格检查**：`npm run lint`
