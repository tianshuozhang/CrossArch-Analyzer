# 后端代码运行文档

## 环境配置

安装python依赖
```
pip install -r requirements.txt
```

安装mysql并配置数据库
```
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
sudo mysql_secure_installation
# 登录
mysql -u root -p
123456
CREATE DATABASE classify_c CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```


## 运行

在CrossArch-Analyzer/code-annotation-backend-master打开项目（以该目录为工作目录）
