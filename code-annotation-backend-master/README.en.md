# Code-Tagger: code markup tool (back-end)

Source code online tagging tool (backend)

Frontend project: [Code-Tagger-Frontend](https://gitee.com/rvsmart-porting/code-annotation)

## Project Objective

This project is [RVSmartPorting Community](https://gitee.com/rvsmart-porting)
an aid for the study of RISC-V software migration techniques.
The goal is to provide a convenient online code annotation tool for analyzing open source software code.
